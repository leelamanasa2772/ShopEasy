# 🛒 ShopEasy

ShopEasy is a full-stack e-commerce web application developed using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

## 🚀 Features

- User Registration
- User Login
- Product Management
- Add Products
- Search Products
- Category Filtering
- Product Details
- Shopping Cart
- Increase/Decrease Quantity
- Order Placement
- Order History
- MongoDB Database Integration
- User Logout

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
